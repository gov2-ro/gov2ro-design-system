# Logos

One SVG per project, e.g. `posturi.svg`, `civtech.svg`, `org.svg`.

- Monochrome, `fill="currentColor"` so it renders white on the header.
- Square viewBox, displayed at 28px high (`.g2-logo`).
- Decorative next to the wordmark: `alt=""` or `aria-hidden="true"`; the project name stays as text.
